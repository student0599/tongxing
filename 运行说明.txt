瞳行 · 软件安装包 运行说明
========================================

本作品为跨平台 Web 应用（Streamlit + 国产大模型），
面向视障群体的 AI 出行与生活辅助智能体。

【方式一】在线访问（推荐，无需安装）
  手机扫码或浏览器打开：
  https://tongxing2026.nat100.top
  （二维码见同目录 qrcode.png）

【方式二】自行部署运行（一条命令）
  1. 安装 Docker（https://www.docker.com）
  2. 复制 .env.example 为 .env，填入智谱 API Key
     （获取：https://open.bigmodel.cn 控制台 → API Keys）
  3. 在本目录执行：
       docker compose up -d
     （或 Ubuntu 系统下执行：bash deploy.sh）
  4. 浏览器打开 http://localhost:8501

【技术栈】
  前端 Streamlit · 视觉 GLM-4V-Flash · 文本 GLM-4-Flash · 语音 Edge-TTS

【核心功能】
  连续导航 / 环境识别 / 文字朗读 / 紧急求助
