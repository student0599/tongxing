# 瞳行 —— 面向视障群体的 AI 出行与生活辅助智能体

> 用手机拍照 + AI 识别 + 语音指引，解决视障者出行中 GPS 导航结束后「最后十米」找不到具体入口、台阶、门牌的痛点，并扩展至文字朗读、紧急求助等生活辅助功能。

## 一句话定位

**手机拍照 → 多模态识别（台阶/障碍/红绿灯/门牌）→ 口语化语音指引 → TTS 实时播报**，为视障者构建一条安全、可感知的出行通道。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 🚶 连续导航 | 设定目的地后连续拍照，结合多轮上下文生成连贯语音指引，解决「最后十米」盲区 |
| 👁️ 环境识别 | 单次拍照，识别台阶、障碍物、红绿灯、斑马线、门牌并语音播报 |
| 📖 文字朗读 | 识别招牌、票据、药品说明等文字并朗读 |
| 🆘 紧急求助 | 描述突发情况，生成自救建议、求助喊话文案与紧急联系电话 |

## 技术栈

| 模块 | 技术 | 说明 |

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置 API Key

```bash
# 复制模板并填写智谱 API Key
cp .env.example .env
# 编辑 .env，填入 ZHIPU_API_KEY
```

> 获取 API Key：https://open.bigmodel.cn/ → 控制台 → API Keys

### 3. 启动

```bash
streamlit run app.py
```

手机访问：同一局域网下，用手机浏览器打开终端显示的局域网地址即可（拍照需 HTTPS 或 localhost 环境，或使用「上传图片」方式）。

## 架构说明

系统采用**子智能体编排架构**，将复杂任务拆分为职责单一、可独立替换的子智能体，由编排器（`src/orchestrator.py`）统一调度：

```
                    ┌─────────────────────────────────────────┐
                    │            Orchestrator（编排器）         │
                    └─────────────────────────────────────────┘
                       │          │          │          │
              ┌────────▼──┐ ┌────▼─────┐ ┌───▼────┐ ┌──▼────────┐
              │ VisionAgent│ │Guidance  │ │  OCR   │ │Emergency  │
              │ (GLM-4V)   │ │Agent     │ │ Agent  │ │Agent      │
              └────────┬──┘ │(GLM-4)   │ │(GLM-4V)│ │(GLM-4)    │
                       │    └────┬─────┘ └───┬────┘ └────┬──────┘
                       │         │           │           │
                       └─────────┴─────┬─────┴───────────┘
                                       │
                              ┌────────▼────────┐
                              │    TTSAgent      │
                              │   (Edge-TTS)     │
                              └─────────────────┘
```

**连续导航流水线**：拍照 → VisionAgent 结构化的环境识别 → GuidanceAgent 结合多轮历史生成指引 → TTSAgent 合成语音播报 → 会话记录写入 `NavigationSession`。

## 部署到公网

可使用 [Streamlit Community Cloud](https://streamlit.io/cloud) 免费部署：

1. 将本项目推送到 GitHub 仓库。
2. 在 Streamlit Cloud 中导入该仓库，主文件填 `app.py`。
3. 在 Secrets 中配置：

```toml
ZHIPU_API_KEY = "你的智谱API Key"
EMERGENCY_CONTACT_NAME = "家人"
EMERGENCY_CONTACT_PHONE = "13800000000"
```
