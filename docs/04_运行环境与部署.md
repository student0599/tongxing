# 运行环境与部署说明

> 大赛要求：程序设计语言、版本号、开发工具和平台、操作系统、软硬件平台及版本号需在提交文档中详细标明。

## 一、开发环境

| 项目 | 说明 |
| --- | --- |
| 程序设计语言 | Python 3.11.9 |
| 开发操作系统 | Windows 11 |
| 开发工具 | Claude Code（Sonnet 4.6）、VS Code |
| 版本管理 | Git |

## 二、关键依赖及版本

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| Streamlit | 1.64.0 | 前端框架 |
| requests | 2.34.2 | HTTP 客户端（调用智谱 API） |
| edge-tts | 7.2.8 | 语音合成 |
| Pillow | ≥10.0.0 | 图像压缩/格式转换 |
| python-dotenv | 1.2.3 | 配置加载 |

## 三、运行平台（不限于以下）

| 平台 | 说明 |
| --- | --- |
| Streamlit Community Cloud | 免费托管，自动 HTTPS，手机拍照可用 |
| 任意云服务器（阿里云/腾讯云等） | Docker 或 systemd + Nginx 部署 |
| 本地运行 | `streamlit run app.py` |

## 四、配置与启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置 API Key（复制 .env.example 为 .env 并填入 ZHIPU_API_KEY）
cp .env.example .env

# 3. 启动
streamlit run app.py
```

部署到公网的完整步骤见根目录 `DEPLOY.md`。

## 五、测试账号

作品为免登录的 Web 应用，无需注册账号。评审时直接访问部署后的公网 URL 即可使用。
（若评审系统要求填写测试用户名/密码，可留空或填写「无需登录」。）
