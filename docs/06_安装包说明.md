# 「安装包」提交说明

> 大赛要求：提交「可在移动终端上运行的可安装文件包」。本文说明 Web 应用（瞳行）如何满足该要求。

## 一、瞳行的性质

瞳行是基于 Streamlit 的 **Web 应用**（运行平台不限，属「跨平台开发工具」）。它不像原生 Android/鸿蒙 App 那样产出 APK，而是通过**浏览器访问公网 URL** 运行。

大赛规则对这类作品有明确兜底条款：

> **「如果是跨平台开发工具，安装包部分请提供对应二维码。」**

因此，瞳行的「安装包」= **公网部署 URL + 二维码**。

## 二、提交物构成

| 提交物 | 说明 | 状态 |
| --- | --- | --- |
| 公网 URL | 作品运行入口（同时满足「联网+公网连通」要求） | 需部署（见 `DEPLOY.md`） |
| 二维码 | 指向公网 URL，评委扫码即用 | 部署后运行 `scripts/gen_qr.py` 生成 |
| PWA 安装能力 | 应用可「添加到主屏幕」，像 App 一样安装 | ✅ 已内置 |

## 三、操作步骤

### 1. 部署公网（前提）

按 `DEPLOY.md` 方案 A（Streamlit Community Cloud）部署，得到形如
`https://<应用名>.streamlit.app` 的公网地址。

### 2. 生成二维码

```bash
pip install qrcode[pil]
python scripts/gen_qr.py "https://<应用名>.streamlit.app"
```

二维码图片生成在 `docs/images/qrcode.png`，随作品提交。

### 3. 添加到主屏幕（可选，评委体验更好）

评委用手机 Chrome/Safari 打开公网 URL 后：
- **Android**：浏览器菜单 →「添加到主屏幕」，即可像 App 一样安装（带「瞳」图标）。
- **iOS**：Safari → 分享 →「添加到主屏幕」。

> 该能力由项目内置的 PWA 配置（`static/manifest.webmanifest` + 应用图标）提供。

## 四、在提交材料中的表述建议

可在《软件设计文档》「运行环境与部署」部分补充说明：

> 本作品为跨平台 Web 应用，无需安装原生包，通过公网 URL 访问；按要求提供对应二维码（见 `docs/images/qrcode.png`）。应用支持 PWA「添加到主屏幕」，可在移动终端获得类原生 App 的安装体验。
