## 二、现场答辩要点

1. **选题价值**：1700 万视障群体 + 「最后十米」盲区，社会价值高、切口小、可落地。
2. **创新点**：多轮上下文连续导航（区别于单次识别）、子智能体编排架构、国产免费技术栈。
3. **技术实现**：GLM-4V-Flash 结构化环境识别 → GLM-4-Flash 口语化指引 → Edge-TTS 播报。
4. **可运行性**：公网 URL 现场演示（已部署）。

## 三、常见质询（Q&A）

- **Q：识别会不会出错？** A：作品定位为辅助手段，输出包含安全提示，不替代盲杖与人工陪护；文档已附免责声明。
- **Q：成本如何？** A：视觉、文本、语音全部免费 API，边际成本接近零。
- **Q：与现有导盲 App 的区别？** A：聚焦「最后十米」多模态环境感知 + 多轮连贯语音指引，而非地图导航。
