# 软件设计文档

> 对应大赛方向一要求：需求分析、设计思路、功能模块、工具平台介绍。

## 一、项目概述

「瞳行」是一款面向视障群体的 AI 出行与生活辅助智能体。作品以手机拍照为输入，通过大模型多模态识别与语音合成，解决视障者出行中 GPS 导航结束后「最后十米」找不到入口、台阶、门牌的痛点，并扩展文字朗读、紧急求助等生活辅助能力。

## 二、需求分析

### 2.1 目标用户
视障及低视力人群，以及需要「无视觉依赖」获取环境信息的老年用户。

### 2.2 核心痛点
GPS 导航只能把人「带到附近」，导航终点与实际目的地之间的「最后十米」是感知盲区：找不到单元门、台阶、药店入口、门牌号，是视障者迷路、跌倒、遇险的高发区。

### 2.3 功能需求
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 连续导航 | 设定目的地后连续拍照，结合多轮上下文生成连贯语音指引 |
| F2 | 环境识别 | 单次拍照识别台阶/障碍物/红绿灯/斑马线/门牌并播报 |
| F3 | 文字朗读 | 识别招牌、票据、药品说明等文字并朗读 |
| F4 | 紧急求助 | 描述情况后生成自救建议、求助喊话、一键拨号 |

### 2.4 非功能需求
- **可用性**：手机端友好，大字体、高对比、大按钮，语音自动播报。
- **低成本**：全部采用免费 API（国产 GLM + Edge-TTS）。
- **可部署**：支持公网部署（Streamlit Cloud / 云服务器 / 容器）。
- **鲁棒性**：API 未配置或调用失败时优雅降级，不崩溃。

## 三、总体设计思路

### 3.1 系统架构（分层）
```
┌─────────────────────────────────────────────┐
│  前端层（Streamlit，手机端友好）               │
│  首页 / 连续导航 / 环境识别 / 文字朗读 / 紧急求助│
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────▼──────────────────────────┐
│  编排层（Orchestrator）                       │
│  协调子智能体、维护会话状态、串联流水线          │
└──────┬───────────┬───────────┬──────────────┘
       │           │           │
  视觉识别      指引生成      语音合成
 (GLM-4V-Flash)(GLM-4-Flash)(Edge-TTS)
       │           │           │
  文字朗读      紧急求助      会话记忆
 (GLM-4V-Flash)(GLM-4-Flash)(NavigationSession)
```

### 3.2 子智能体编排
系统采用**子智能体架构**，将复杂任务拆分为五个职责单一、可独立替换的子智能体：

| 子智能体 | 模型/技术 | 职责 |
| --- | --- | --- |
| VisionAgent | GLM-4V-Flash | 图片 → 结构化环境 JSON |
| GuidanceAgent | GLM-4-Flash | 环境 + 历史 → 口语化指引 |
| OCRAgent | GLM-4V-Flash | 图片 → 文字内容 |
| EmergencyAgent | GLM-4-Flash | 情况 → 求助方案 |
| TTSAgent | Edge-TTS | 文字 → 语音 MP3 |

### 3.3 核心数据流
```
拍照 → VisionAgent(结构化环境) → GuidanceAgent(结合多轮历史) → TTSAgent(语音) → 播报
                                          ↑
                              NavigationSession(会话记忆)
```

## 四、功能模块详细设计

### 4.1 连续导航（F1）
- 用户设定目的地，`NavigationSession` 记录出行目标与每轮「环境 + 指引」。
- 每轮拍照后，GuidanceAgent 携带最近 3 轮历史生成指引，避免重复、保持连贯。
- 更换目的地自动清空会话，支持「重新开始」。

### 4.2 环境识别（F2）
- 单次拍照 → VisionAgent 输出结构化 JSON（场景类型/障碍物/台阶/红绿灯/门牌/文字/安全建议）→ 指引 + 播报。

### 4.3 文字朗读（F3）
- 拍照 → OCRAgent 提取全部文字（招牌/票据/药品说明）→ 大字号展示 + TTS 朗读。

### 4.4 紧急求助（F4）
- 用户描述情况 → EmergencyAgent 输出严重程度/自救建议/求助喊话/通话话术。
- 前端大字广播（供路人查看）+ 语音播报 + 一键拨号（110/120/紧急联系人）。

## 五、关键技术

1. **多模态环境识别**：通过提示词约束 GLM-4V-Flash 输出结构化 JSON，鲁棒解析（兼容 markdown 包裹与纯文本退化）。
2. **多轮上下文管理**：`NavigationSession` 保存出行全程记录，只取最近 3 轮喂给模型，兼顾连贯性与上下文长度。
3. **口语化指引生成**：提示词工程约束「安全优先、30 字内、方位词、不重复」，temperature 0.5 兼顾自然度。
4. **异步语音合成**：Edge-TTS 流式分片聚合为 MP3，前端以 base64 自动播放。
